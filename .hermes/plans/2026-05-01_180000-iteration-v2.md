# Iteration v2: AI Daily Brief 全面升级

## 目标
将 GitHub AI 热榜日报升级为全功能的信息聚合 + 展示平台。

---

## Phase 1: 增强数据源（基础）

### 1.1 多源聚合
| 源 | API | 频率 |
|----|-----|------|
| GitHub Trending | `/search/repositories?q=topic:ai` | 每6h |
| Hugging Face | `huggingface.co/api/models?sort=downloads` | 每6h |
| ArXiv | `export.arxiv.org/api/query?search_query=cat:cs.AI` | 每天 |
| Hacker News | `hacker-news.firebaseio.com/v0/topstories` | 每6h |

**文件变更:**
- `app/services/github.py` → 拆分出 `app/services/fetchers/` 包
- 新增: `huggingface.py`, `arxiv.py`, `hackernews.py`
- `app/services/report_service.py` → 合并多源

### 1.2 AI 摘要生成
- 接入 LLM（用 `httpx` 调 DeepSeek/OpenAI API）生成日报文案
- 不用 LLM 则用规则摘要（已有）

**文件变更:**
- 新增: `app/services/summarizer.py`
- `app/core/config.py` → 加 `llm_api_key`, `llm_base_url`

## Phase 2: API 增强

### 2.1 分页 & 搜索 & 排序
```
GET /api/v1/daily-reports?page=1&per_page=10&sort=date&order=desc&q=llm
```

### 2.2 收藏 & Tag 系统
```
POST   /api/v1/favorites          # 收藏某天的日报
DELETE /api/v1/favorites/{id}
GET    /api/v1/favorites
```

### 2.3 趋势图表数据
```
GET /api/v1/trends?days=30
```
返回每日项目数、语言分布、关键词热度等统计。

### 2.4 WebSocket 实时推送
```
WS /api/v1/ws/reports
```
新日报生成时主动推送给所有连接客户端。

**文件变更:**
- `app/api/routes.py` → 拆分为 `app/api/v1/` 包
- 新增: `reports.py`, `favorites.py`, `trends.py`, `websocket.py`
- `app/models/schemas.py` → 新增 Pydantic 模型
- `app/models/daily_report.py` → 加 Favorite ORM 模型

## Phase 3: 前端 React 面板

### 3.1 技术栈
- React + TypeScript + Vite
- TailwindCSS
- Recharts（趋势图表）
- WebSocket 客户端

### 3.2 页面
| 路由 | 功能 |
|------|------|
| `/` | 今日日报（默认） |
| `/history` | 历史日报列表 + 搜索 |
| `/trends` | 趋势图表（语言、项目数、关键词） |
| `/favorites` | 收藏列表 |

### 3.3 组件
- `ReportCard` — 日报卡片
- `RepoTable` — 项目表格
- `TrendChart` — 趋势折线图
- `LanguagePie` — 语言饼图
- `SearchBar` — 搜索 + 日期筛选

**文件变更:**
- 新建: `frontend/` 目录（Vite 项目）

## Phase 4: 部署 & 基础设施

### 4.1 PostgreSQL 替换 SQLite
- `docker-compose.yml` → 加 `db` service
- `app/core/config.py` → `DB_URL` 默认改 PostgreSQL
- `app/core/database.py` → 加异步连接池

### 4.2 Nginx 反代 + HTTPS
- `nginx.conf` — 反向代理 /api 到 FastAPI，/ 到前端
- 可选: Let's Encrypt 自动证书

### 4.3 CI/CD (GitHub Actions)
- `.github/workflows/ci.yml`
  - `pytest` 测试
  - 构建 Docker 镜像
  - 自动部署到服务器

### 4.4 健康检查增强
- `GET /health` → 返回数据库状态、上次抓取时间、各数据源状态

**文件变更:**
- `docker-compose.yml` → 重写
- 新增: `nginx/nginx.conf`, `.github/workflows/ci.yml`
- `app/main.py` → health endpoint 增强
